YenBaht setup

Two wallets (¥ and ฿), quick manual entry, and automatic recording of Suica / Apple Pay payments.

1 · Install 2 · Daily use 3 · Google Sheet 4 · Suica auto-record 5 · PayPay 6 · KBank More

1 · Install on your iPhone

  1. Open this site in Safari.
  2. Tap Share → Add to Home Screen → Add.
  3. From now on, open YenBaht from the home-screen icon.
The home-screen app and a Safari tab keep separate data. Always use the icon.

2 · Daily use

  • Cash expense: type the amount → tap a category. That's it (2 taps). Undo appears for a few seconds.
  • Wallet: picked by your time zone (Japan → ¥, Thailand → ฿). Tap a wallet card to switch.
  • Another day: tap Today before saving.
  • Income or Transfer (e.g. sending yen home as baht): tap the switch above the amount.
  • Starting balance: ⚙ Settings → Balances → type what you have now → Set.
  • Fix a record: History → tap it.
  • Hold ⌫ to clear the amount.

3 · Connect a Google Sheet One time, about 5 minutes. Easiest on a computer.

This is the "mailbox" your iPhone Shortcut drops payments into. It's also a backup of everything you record.

  1. Open sheets.new (signed in to Google). Name it YenBaht.
  2. Menu Extensions → Apps Script.
  3. Delete everything in the editor and paste the code below.
  4. On the line const SECRET = 'change-me'; replace change-me with your own secret word (e.g. mango-tokyo-42). Save (Ctrl+S).
  5. Deploy → New deployment. Click the ⚙ next to "Select type" → Web app.
    Execute as: Me. Who has access: Anyone. → Deploy.
  6. Authorize access → choose your account. Google says "Google hasn't verified this app" — it's your own script, so click Advanced → Go to … (unsafe) → Allow.
  7. Copy the Web app URL (ends with /exec). Send it to your iPhone (LINE Keep, or email yourself).
  8. On the iPhone: YenBaht → ⚙ → Auto-record & backup → paste the URL, type your secret word → Connect. You should see ✓ Connected.
  9. Tap Send test. Close Settings — a ¥1 "Test payment" is waiting to be sorted. Delete it.
"Anyone" is needed because a Shortcut can't sign in to Google. Your secret word is what keeps others out — don't share the Shortcut URL.

4 · Auto-record Suica & Apple Pay On the iPhone, in the Shortcuts app. About 3 minutes.

Every time you tap Suica (or any Apple Pay card), the iPhone sends the amount and shop name to your sheet. YenBaht picks them up when you open it.

  1. In YenBaht: ⚙ → Copy Shortcut URL.
  2. Open Shortcuts → Automation tab → + (New Automation).
  3. Choose Transaction (Wallet).
  4. Under Card, pick Suica (and any other Apple Pay cards you pay with). Leave the other options as they are. Select Run Immediately → Next.
  5. Tap New Blank Automation, then Add Action and search for Get Contents of URL.
  6. Tap the blue URL placeholder and paste the Shortcut URL.
  7. Tap the › on the action to show more: set Method to POST and Request Body to JSON.
  8. Tap Add new field → Text three times and fill them in:
    KeyValue (tap the box, then pick from the variable bar)
    amountShortcut Input → tap it again → Amount
    merchantShortcut Input → Merchant
    cardShortcut Input → Card or Pass (or Name)
  9. Tap Done.

Check it works

Pay with Suica (a drink from a vending machine is fine). Open YenBaht — you'll see "1 auto-recorded payment needs sorting". Tap it, tap a category. Next time the same shop is sorted for you automatically, and train/bus fares go straight to Transport.

If nothing arrives: Settings app → Mobile Service (Cellular) → make sure Wallet is allowed to use mobile data. Some payments arrive without an amount (an iOS quirk) — the app asks you to type it or delete it.

5 · PayPay About once a month, ~6 taps

PayPay doesn't let other apps read your payments, but it can export a month of history as a CSV file.

  1. In PayPay, open your 取引履歴 (transaction history) and look for the download / CSV option. Pick a month and request it.
  2. When it's ready (PayPay keeps it for 24 hours), download it and Save to Files.
  3. In YenBaht: ⚙ → Import PayPay history (CSV) → pick the file → check the list → Import.

Menu names can vary between PayPay versions. Importing the same month twice is safe — duplicates are skipped. PayPay top-ups (チャージ) are skipped because that's just moving your own money. If the file isn't recognised, the app shows its first line so the importer can be adjusted.

6 · Auto-record KBank (baht) Uses KBank's text-message alerts. About 5 minutes.

KBank doesn't let other apps read your account, but it can text you every time money goes in or out. Your iPhone forwards each KBank text to your Google Sheet, and YenBaht reads the amount, money in or out, and the time. That covers transfers, PromptPay / QR payments, debit card and ATM.

Before you start

  • Turn on KBank SMS alerts ("SMS ขยันบอก" / SMS Transaction Alert) in K PLUS. KBank charges a yearly fee per account (฿199 when this guide was written).
  • The Thai phone number registered with KBank must get its texts on this iPhone (for example a Thai eSIM as a second line). Texts usually still arrive while roaming in Japan.
  • Section 3 (Google Sheet) must be done. If you set it up before this KBank feature existed, paste the latest code into Apps Script again and publish a new version (see the end of section 3).

Make the automation

  1. Open one KBank alert in Messages. Find a piece of text that is in every KBank alert but not in other texts. Your masked account number (something like X123456X) is ideal.
  2. In YenBaht: ⚙ → Copy Shortcut URL (the same one as for Suica).
  3. Shortcuts → Automation → + → Message.
  4. Message Contains: type the text from step 1. Leave Sender empty (bank senders can't be picked). Choose Run Immediately → Next.
  5. New Blank Automation → add Get Contents of URL → paste the URL → tap ›: Method POST, Request Body JSON.
  6. Add two Text fields:
    KeyValue
    smsShortcut Input (if you can pick a part of it, choose Content)
    banktype KBank
  7. Tap Done.

Check it works

  • Before any money moves, copy an old KBank text and paste it in YenBaht → ⚙ → KBank texts. It shows what the reader understands.
  • After the next KBank text, open YenBaht: the payment is waiting in Sort with the original text underneath.
KBank doesn't send alerts between 22:00 and 07:00 — night payments arrive in the morning, and YenBaht uses the time written in the text. If a payment was also entered by hand, or it's the baht side of a Transfer you recorded, Sort shows "Already recorded?" so you can skip it with one tap. A text the reader can't fully understand still arrives: you type the amount in Sort. Report the wording of such texts (hide account numbers) so the reader can be improved — earlier texts get re-read automatically.

More (optional)

Log PayPay or a Thai bank app right after you pay

Instead of the monthly CSV (or KBank texts), a Shortcut can pop up "How much?" every time you close the app:

  1. Shortcuts → Automation → + → App → choose PayPay (or K PLUS, SCB EASY…) → Is Closed → Run Immediately.
  2. Add action Ask for Input → Input Type: Number, prompt "How much?".
  3. Add Get Contents of URL with the same Shortcut URL, POST, JSON, fields: amount = Provided Input, merchant = PayPay, and for Thai apps also wallet = THB.

Pick one method for PayPay — using both the pop-up and the CSV import records each payment twice. Cancel the pop-up when you only checked your balance.

Backup

With the Google Sheet connected, every record is copied there automatically. You can also use ⚙ → Export backup any time.
